# Паспорт Проекта

## Что Это

Кратко описать проект простыми словами.

## Живой Проект

- URL:
- Бот/сервис:
- Где запущен:

## Что Нельзя Ломать

- Главные пользовательские сценарии.
- Админка.
- Формы.
- Оплаты.
- База данных.
- Webhook-и.

## Как Проверять

Основная команда:

```bash
./scripts/check.sh
```

Для сайта:

```bash
./scripts/browser-check.sh
```

## Как Выкладывать

Живой проект не выкладывать без фразы:

```text
Разрешаю выложить на живой проект
```


## Локальная Проверка Без Живой Выкладки

После изменений Codex должен запустить:

```bash
./scripts/local-verify.sh
```

В конце Codex должен написать: `Готово к выкладке на живой проект` или `Нельзя выкладывать: есть проблемы`.
