## СДЕЛАНО (задеплоено, работает в проде)

- Формулировки: убран «ИИ/нейросеть» из клиентских текстов → «по ветнормам, проверяет
  специалист»; в оферте/политике автоматизация раскрыта мягко. Сроки везде «до 3 раб. дней».
- Поток ревью: `paid → processing → review → done` (+ `rework`). Авто-проверка (агент) =
  инварианты `reconcile.py`, затем кинолог в `/admin/review`: одобрить / правка текстов /
  на переделку с замечаниями. Клиенту НИЧЕГО не уходит автоматически.
- Комбо-заказы: отдельные sidecar (natural/dry), две формы правки.
- Доставка по каналам: email / Telegram (deep-link) / ВКонтакте (`VK_TOKEN`); выбор канала в анкете.
- Инвариант «суточная норма = сумма групп» в `reconcile.py` + инъекция в `canary.py` (5/5).
- Скриншоты примера на лендинге перегенерены, слайдер переразмечен на чистые страницы.
- Вебхук YooKassa перепроверяет платёж в API (`app._verify_yookassa_payment`).
