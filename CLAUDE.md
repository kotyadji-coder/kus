# kus — калькулятор рациона для собак

Веб-сервис: считает индивидуальный рацион (BARF/варка), рендерит PDF-отчёт, бот в Telegram.
Ядро: `calculator.py` (расчёт+подбор продуктов), `pdf_generator.py` (HTML/PDF-отчёт),
`reconcile.py` (инварианты согласования), `bot.py`/веб (FastAPI).

## Самоулучшение: ХРАПОВИК (главное правило)

Модель не обучается — **поднимается «пол» качества и не может опуститься**. Поэтому:

> **Ни один баг не чинится без теста, который бы его поймал.**

Чиня любой баг согласования (сводка ↔ меню ↔ список покупок):
1. **Корень, не симптом** — правь `calculator.py`/`pdf_generator.py`, не маскируй проверку.
2. **Инвариант** — если это новый класс, добавь проверку в `reconcile.py` (единый источник;
   дублировать проверки в evals/fuzz/snapshot запрещено — только туда).
3. **Регресс-профиль** — добавь воспроизводящий профиль в `PROFILES` в `evals.py` с `label`,
   описывающим баг. Так гейт ловит его детерминированно каждый раз.
4. **Рацион ветеринарно корректен** — фикс не должен ломать диету (мелкие собаки, щенки,
   гиганты-заворот, стоп-листы — частые углы).

## Ворота (обязательно перед коммитом фикса)

```
bash tools/check.sh          # канарейка + golden-снапшот + согласование. Exit≠0 = регресс.
```
- Если рендер отчётов изменился ОЖИДАЕМО — одобри эталон: `./venv/bin/python tools/snapshot.py --update`.
- `tools/fuzz.py [N] [seed]` — поиск новых углов (реалистичные профили). Exit 1 при нарушении.
- `tools/canary.py` — «детектор жив?» (впрыск известных багов, должны ловиться).
- Деплой только через `bash tools/deploy.sh` (гейт → рестарт kus.service). **Гейт на коммите нельзя**
  (авто-backup-крон коммитит всё подряд).

## Топология (важно)

- `/mnt/5.42-opt/kus` = sshfs-монтаж сервера **5.42** (UTC). Правки тут = правки на сайте.
- **5.42 НЕ достучивается до api.telegram.org** — Telegram слать только с Амстердама.
- Ночной самоконтроль: проверки на 5.42, дайджест+агент с Амстердама (локальный клон `/root/kus`,
  крон 06:20/08:00 MSK). Скрипты — `tools/night.sh` (дайджест), `tools/night_agent.sh` (Claude-агент).

## Если ты — НОЧНОЙ АГЕНТ (запущен из tools/night_agent.sh)

- Работаешь в **локальном клоне `/root/kus`**, НЕ в проде. **Не трогай прод**: ни рестарта сервиса,
  ни правок вне репозитория, ни мержа.
- Почини баг по правилам храповика выше, добейся зелёных ворот, сделай `git commit`.
- **НЕ делай `git push` и НЕ открывай PR** — это делает скрипт после независимого прогона ворот.

## Меню: слоты кормлений

`DayMenu`: `morning` (Утро) · `midday` (День) · `afternoon` (Полдник) · `evening` (Вечер).
- 2 кормления: Утро+Вечер. 3 (гиганты/гастрит): вечерний пучок пополам → День+Вечер.
- 4 (щенки <4 мес): оба пучка пополам → Утро+День / Полдник+Вечер.
- Любая новая итерация по слотам ДОЛЖНА включать `afternoon` (иначе недосчёт у щенков).
