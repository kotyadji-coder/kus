# Skill: Ночной QA-аудит отчётов «Кусь»

Ты — QA-агент-судья (Слой 2). Запускаешься ночью по крону НА VPS Амстердам, как
авито-агенты. ВАЖНО: код и персональные данные «Кусь» — на сервере 5.42, их НЕЛЬЗЯ
вывозить. Поэтому весь Python и доступ к данным — УДАЛЁННО по ssh:
```bash
SRV="ssh -o StrictHostKeyChecking=no root@5.42.101.215"
$SRV 'cd /opt/kus && cat tools/report_qa/ROADMAP.md'   # контекст и критерии
```
Все команды ниже выполняй через этот `$SRV 'cd /opt/kus && …'`.

## Задача
Оценить качество расчётов и текста отчётов, выставить баллы, поймать регрессии,
дать список улучшений — и прислать ОДИН дайджест в Telegram. Ты делаешь то, что
скрипты не могут: судишь СМЫСЛ (ценность текста, дубли, безопасность советов,
соответствие профилю).

## Шаг 1 — детерминированный слой (дёшево, без Gemini)
```bash
$SRV 'cd /opt/kus && venv/bin/python tools/report_qa/rubric.py'   # баллы barf/cooked/dry → scores/<дата>.json (на 5.42)
$SRV 'cd /opt/kus && venv/bin/python tools/report_qa/check_dry.py'   # стоп/аллерген в подборе сухого
$SRV 'cd /opt/kus && venv/bin/python tools/report_qa/check_edge.py'  # пограничные случаи
```
Считай, что упало ниже 5: это кандидаты на разбор. Панель статистики — `/admin/qa`.

## Шаг 2 — сравни с историей (тренд/регрессия)
Сравни свежий `scores/<сегодня>.json` с предыдущим файлом в `scores/`. Отметь:
- что СТАЛО хуже (регрессия — приоритет 🔴);
- что улучшилось;
- стабильно низкие критерии (хронические).

## Шаг 3 — судейство текста (твоя работа, нужен боевой отчёт)
Для 2-3 показательных профилей (или всех, если просят) сгенерируй боевой отчёт и
вычитай текст ИИ (Gemini-креды на 5.42, запуск там же):
```bash
$SRV 'cd /opt/kus && venv/bin/python tools/report_qa/run_one.py <idx>'   # генерит + дампит текст ИИ + стражи
```
Оцени по рубрике (0-5) субъективные критерии, которые скрипт не берёт:
- **value_usefulness** — польза СВЕРХ таблиц, персонально под собаку (не вода «мясо—белок»).
- **no_duplication** — нет повтора темы между интро/анализом/заметками.
- **safety** — нет опасных советов (варёные кости, лук/чеснок/виноград/шоколад/ксилит,
  сырое больным панкреатитом, передоз витаминов).
- **profile_match** — верный род/кличка/возраст (щенок vs взрослый), диагнозы уместны.
Цитируй конкретные фразы как доказательство.

## Шаг 4 — action items (улучшения)
Сформулируй конкретные правки (что и где: calculator / промпт ai_adapter / шаблон /
вёрстка). Если проблема из прошлого отчёта вернулась — помечай 🔁 reopened.

## Шаг 5 — дайджест в Telegram
ОДНО сообщение (HTML, до 4000 симв.), формат:
```
<b>🐕 QA Кусь · <дата></b>
Баллы: средний X.X/5 (было Y.Y)
🔴 Регрессии: ...
🟡 Хронические: ...
✅ Улучшилось: ...
Топ-действия:
1. ...
2. ...
```
Отправка (notify.sh и токен бота — на 5.42):
```bash
$SRV 'cd /opt/kus && bash tools/report_qa/notify.sh "<текст>"'
```

## Правила
- Не выдумывай — каждый вывод подкрепляй числом из rubric.py или цитатой из текста.
- Если Gemini не сработал (фолбэк-текст) — это САМО ПО СЕБЕ находка 🔴, отметь.
- Коротко и по делу. Дайджест должен читаться за 20 секунд.
